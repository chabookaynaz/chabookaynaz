# MOSFET: History, Operation and Scaling

31-slide academic presentation co-authored by **Mania Tahery and Aynaz Chabouk** (names as shown on the title slide).

[Download the original PowerPoint](mosfet1.pptx)

Topics include MOS capacitors, inversion-channel formation, threshold voltage, operating regions, CMOS applications, photolithography, scaling and short-channel challenges.

This is a coursework presentation, not a transistor fabrication or device-simulation project. The original deck is preserved, including its figures and wording. Some numerical statements and technical simplifications require checking against primary references before reuse. No license is added for third-party figures.
